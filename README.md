# tooltip-plus-wow-forever

Source for **Tooltip+**, a World of Warcraft: Forever addon that positions and customizes the default game tooltip.


## Requirements

- WoW Forever beta (`## Interface: 16001`)
- Python 3, only if you use the install script

## Docs

- [Local development](docs/development.md) — copy `src/` into AddOns, or install with the script
- [Production build](docs/release.md) — write a release folder without installing it
- [Addon](docs/addon.md) — file layout and slash commands
